# Typing_Speed_Test

A **client-server web application** to test typing speed and accuracy. Users type a given paragraph within a time limit, and the app calculates Words Per Minute (WPM), time taken, and typing accuracy.  
This project is built using **Python Flask** for the backend and plain **HTML/CSS/JavaScript** for the frontend.

## Features

- Random paragraphs (~50 words each) to type.
- Multiple paragraph categories: technology, stories, travel, motivational, moral tales.
- Change paragraph anytime before starting.
- **Timer options**: 30s, 60s, 120s.
- Auto-submit when time runs out.
- Displays results: WPM, time taken, accuracy.
- Responsive full-width layout with a solid red background.
